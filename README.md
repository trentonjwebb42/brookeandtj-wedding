# brookeandtj.wedding

Wedding website for Brooke & TJ: save the date, invitations, and RSVP.

- **Domain:** brookeandtj.wedding (registered on Cloudflare, DNS-only records pointing to Vercel)
- **Hosting:** Vercel
- **Brand:** see `/brand`: color palette, typography, and `tokens.css`

## Brand at a glance

| Role | Name | Hex |
|---|---|---|
| Identity | Ivory | `#FFFFFF` per guideline (swatch reads as a warm off-white) |
| Identity | Black | `#000000` |
| The environment | Olive | `#50563E` |
| The surprise | Oxblood | `#391613` |
| The venue | Taupe | `#B2A691` |

**Type:** Ms Claudy + Bellefair for titles, Adobe Garamond Pro for body.
