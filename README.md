# brookeandtj.wedding

Wedding website for Brooke & TJ: save the date, invitations, and RSVP.

- **Domain:** brookeandtj.wedding (registered on Cloudflare, DNS-only records pointing to Vercel)
- **Hosting:** Vercel
- **Brand:** see `/brand`: color palette, typography, and `tokens.css`

## Structure

- `index.html`: the live site, currently the Phase 1 save-the-date edition. To switch on the full site and RSVP, set `var SITE = { phase: 2 };` near the bottom of the file.
- `drafts/`: earlier design versions, kept for reference (not deployed)
- `brand/`: guidelines (not deployed)

## Brand at a glance

| Role | Name | Hex |
|---|---|---|
| Background | Limestone | `#F2EEE4` |
| Text | Ink | `#1A1A18` |
| The only accent | Shutter Green | `#2E3B30` |
| Supporting | Olive | `#6B6E4A` |
| Supporting | Stone | `#BBAE9B` |

**Type:** Orpheus Pro for names, headings and small caps; Adobe Garamond Pro (Regular + Italic) for body and italics.
